## 🛠 結構

```
demos/
├── index.html       ← 作品集首頁
├── 7dtd/            ← 七日殺攻略
│   └── index.html
└── README.md
```

每個資料夾是一個獨立作品，網址會自動對應到資料夾路徑。

## 🚀 新增作品的流程

1. 在這個 repo 建一個新資料夾
2. 放進 `index.html` 與相關檔案
3. 編輯 `index.html`（作品集首頁）把新作品加進列表
4. Commit & push
5. 30 秒後 `shawn77569.github.io/demos/[資料夾名]/` 就能打開
