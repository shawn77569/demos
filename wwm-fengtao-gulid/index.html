新手必讀 · 基礎觀念

如果你是第一次打俠境，這裡先把術語和規則講清楚。已經熟練的老手可以直接跳到 BOSS 章節。

俠境
10-MAN RAID
10 人副本玩法，每週可挑戰一次拿首通獎勵（不消耗心力）。百業俠境是另一個獨立次數，加入百業且通關後可額外拿一次獎勵。
首領天賦
BOSS TALENTS
每隻 BOSS 都有自己的天賦樹，分 1-1、1-2、1-3、2-1、2-2、2-3 六個節點。要在特定條件下通關才解鎖（例如「撞滿六顆石頭再殺 BOSS」）。提供永久增傷或減傷加成。
卸勢
PARRY
看到 BOSS 的紅光技，按防禦鍵反彈，化解傷害並消耗 BOSS 真氣。本副本許多技能都靠卸勢化解。黃光技則必須走位躲避，不可卸勢。
紅光 / 黃光
RED / YELLOW TELL
紅光=可卸勢、黃光=必須躲開（不可卸）、紫色牽引線=點名你（要拉走或站位）。看到光的顏色就知道怎麼處理。
站位術語
ROLES
T = 坦克（拉仇恨）；奶 = 治療；DPS = 輸出；承傷 = 指定挨技能的人（通常 T 兼任）。本副本建議 1T + 1 輔 + 8 DPS 或 8 輸出 + 2 治療。
必帶奇術
SKILLS LOADOUT
輸出：簫吟千浪（聚怪/位移）+ 騎龍回馬（高傷處決）；機動：凌雲踏（快速貼近 BOSS）；治療：無相金身（群體免傷）。
明光（鎮關吼專用）
STAR CORE
場地中央會出現一顆星核「明光」，是鎮關吼戰的核心。明光血量降到 0 → 團滅。BOSS 的多個技能就是針對明光，玩家要全程保護它。
聖旨（五殘專用）
DECREE ZONES
五殘二階段刷出兩個聖旨。平常不要進入——待超過 3 秒會強制跪拜掉血，頂上倒計時歸零還會放 AOE。只有遇到無常索命這種秒殺機制時才進去下跪躲避；某些機制反而要把 BOSS 引過去打掉聖旨。
— 首 領 之 壹 —

鎮 關 吼

難度較高的星狮 BOSS，所有機制圍繞「傳送門」與「明光保護」展開。看似技能繁多，掌握核心三原則後其實有章可循：門要對線、光要護嚴、卸要及時。

散關隘口戰場示意：明光位中央，玩家環形輸出，三面有鎮關壁可供撞碎

核心規則
明光血量歸零 = 團滅。BOSS 多數技能都會直擊明光，玩家全程要監控明光血量，遇到明光相關機制（碎日追擊、飛星六連）優先處理。
壹
月焰
扇形 AOE

機制描述

BOSS 朝某個方向噴出大範圍扇形火焰，傷害極高且範圍很廣（約 50m），正面吃滿幾乎秒殺。

應對方法

  • 跑到鎮關吼的兩側或背後
  • 距離他至少 50m 以上
  • 不要正對 BOSS 嘴部方向
注意
遊戲中顯示的技能朝向與實際 BOSS 技能朝向可能有偏差，看 BOSS 模型本體方向為準，不要看特效。

玩家跑到 BOSS 兩側/背後即安全

貳
月曜星陨
引導機制

機制描述

鎮關吼會朝某個方向衝鋒。場地邊緣有三面鎮關壁，要利用 BOSS 的衝鋒方向把鎮關壁撞碎。

應對方法

  1. BOSS 出技能前會點名一名玩家（通常是最遠的人）
  2. 被點名玩家站在鎮關壁正前方，讓 BOSS 衝鋒路徑通過鎮關壁
  3. 確保「BOSS → 玩家 → 鎮關壁」三點一線
  4. 等紫色牽引線消失後即可跑位

引導 BOSS 衝鋒方向撞碎鎮關壁

參
月隙
傳送門 · 工具

機制描述

BOSS 點名兩位玩家，腳下生成兩個傳送門。站上傳送門即可瞬移到另一個門。不是傷害技能，是後續機制的關鍵工具。

應對方法

  • 被點名的兩位玩家一近一遠站位：
  • 一人放在中場（靠近明光附近）
  • 一人放在場地最外圍（遠離 BOSS）
  • 確保「傳送門 → 安全區」連成一條快速逃生路線
關聯技能
月隙會搭配黑洞、飛星六連使用。先放好傳送門，後續團滅機制才能用門逃脫。

兩個傳送門：一中場一外場，建立逃生通道

肆
碎日追擊
明光保護 · 卸勢

機制描述

BOSS 朝明光發起衝鋒，途中會對明光造成大量傷害。明光血量低時，此技不卸 = 直接團滅。

應對方法

  • 站在 BOSS 與明光之間
  • 看到紅光起手立刻卸勢反彈
  • 多人同時卸勢更穩定
注意
BOSS 的紅光顯示有 bug，看不到紅光也要根據動作判斷。看到 BOSS 對著明光蓄力 → 立刻卡位卸勢。

站在 BOSS 與明光之間卸勢化解

伍
地裂咒
兩段範圍 · 卸勢

機制描述

兩段攻擊：

  1. 第一段：BOSS 以自身為中心發動中等傷害（可卸）
  2. 第二段：鎖定一名玩家，5 秒後以該玩家為中心再次發動（可卸）

應對方法

兩段都是可卸勢的紅光技，看到光直接卸即可。被鎖定的玩家不要亂跑，原地卸勢就好。

小提醒
本副本中最容易處理的技能之一。沒卸到也不會團滅，傷害可控。

兩段中心範圍攻擊，皆可卸勢化解

陸
黑洞
秒殺機制 · 必逃

機制描述

BOSS 持續牽引所有玩家到他身邊，被吸到身邊就是秒殺團滅。

應對方法

  1. 使用之前放好的傳送門遠離 BOSS
  2. 沒搭好傳送門 → 用騎龍回馬位移逃脫
  3. 找掩體（如果場地有可阻擋牽引的物件）
關鍵
黑洞是月隙存在的意義。看到 BOSS 開始牽引立刻往傳送門跑，否則團隊整體會被拉到 BOSS 腳下被秒。

內門靠 BOSS、外門在場外，踩內門瞬移逃脫

柒
飛星六連
明光保護 · 搬運

機制描述

明光旁邊會刷新出 6 塊黑曜石，每塊都有黃光爆炸範圍。如果黃光波及到明光 → 明光大量掉血。

應對方法

  1. 看到 6 塊石頭出現，全員分工搬運
  2. 每人搬一塊到場地最外側
  3. 確保黃光範圍不會碰到明光
  4. 搬完後立刻離開石頭旁邊（避免被自爆）
效率技巧
可以用之前放好的傳送門快速搬運。每人帶一個石頭通過傳送門到場地邊緣，效率最高。

6 塊石頭由明光旁搬到場地最外側

捌
月隕
過場動畫 · 終局

機制描述

鎮關吼剩下 10% 血量時，明光會變成另一頭獅子協助戰鬥，純粹是過場動畫。

應對方法

沒有特殊應對，繼續輸出鎮關吼到死即可。前面機制處理得當的話，這段是純粹的爆發階段。

爆發時機
月隕前後是集中輸出視窗，把所有 CD 留到這時打出來。如果 DPS 夠，可以一波斷尾收掉。

10% 血觸發過場，正常輸出即可

五 殘

相比鎮關吼，五殘難度較低，一階段幾乎沒有團滅點，重點在二階段四大機制：無常索命、飛羽追魂、哭喪電網，以及穿插的索魂追命圈。場地兩個聖旨是策略工具——平常別進，秒殺技才用。

五殘戰場示意：兩個聖旨區（綠色）為策略性機制工具，非必要時不進入

一階段（簡單）

一階段相對簡單，主要是壓血。BOSS 有兩條血條（地禍、天聽），同時打掉即可進入二階段。場地上的聖旨也是二階段才刷出來，所以一階段不用管它。沒什麼大團滅點，正常輸出加躲技能就過了。

提醒
二階段聖旨刷出後才是真正考驗。記得平常時間不要待在聖旨範圍內，只在無常索命時跑進去下跪。

二階段主要機制

壹
無常索命
秒殺機制 · 必躲

機制描述

五殘跳到空中，將所有玩家朝自己方向拉扯。被吸到 BOSS 附近 → 秒殺（類似獅子吸的結算）。

應對方法

  1. 看到 BOSS 跳起，立刻往聖旨區域跑
  2. 進入聖旨範圍後下跪
  3. 等階段結束再起身
注意
不建議用三段跳規避——三段跳容易被空中拉扯抓住直接秒殺。聖旨下跪是最穩定的解法。

全員跑進聖旨區下跪，等技能結束

貳
飛羽追魂
點名追擊 · 引導

機制描述

BOSS 點名多名玩家（頭頂出現 ↓ 圖示），對其持續追擊高傷害。

應對方法

  1. 被點名玩家保持移動，留住體力
  2. 引導 BOSS 的攻擊軌跡碰瓷聖旨
  3. 讓 BOSS 把聖旨打掉，化解傷害
注意
未被點名的玩家不要靠近被點名玩家，否則羽毛會刮到附近的人。建議全場保持移動，自己避讓。

被點名玩家引 BOSS 攻擊碰瓷聖旨

參
哭喪電網
配對機制 · 高難

機制描述

地圖上刷出 4 個哭喪棒，造成多段傷害。後續會招小怪做大範圍攻擊干擾。

應對方法

  1. 把4 個哭喪棒搬到場上適當位置
  2. 兩兩相同顏色圖示的棒子放在一起，拉成一條電網
  3. 後續刷小怪時，被鎖定的玩家帶小怪去撞電網暈住它
  4. 全員集火秒掉小怪
進階技巧
兩條電網建議擺成直角狀，覆蓋範圍更大。理想配置是「鳥 → 電網 → 被點名玩家」三點一線，電網夾在中間。

電網直角擺放、鳥電網玩家三點一線

肆
烏護殺意
配合電網 · 引導

機制描述

五殘召喚烏護，點名隨機玩家發起衝鋒。被點名玩家需要引導烏護撞到電網上暈住它。

應對方法

  1. 被點名玩家保持移動
  2. 把烏護引導撞向已擺好的電網
  3. 另一位玩家可以幫忙舉電棒拉電網配合走位
  4. 暈住後全員集火秒殺烏護
配合默契
這個機制要求哭喪電網先擺對位置。如果電網擺得不好，烏護根本撞不到，會變成持續放火造成大量減員。

引導烏護撞電網暈住，再集火秒殺

伍
索魂追命圈
穿插機制 · 跑動躲

機制描述

五殘隨機點名玩家，腳下落下巨大黃圈（俗稱「放電圈」）。黃圈會：

  1. 第一段：點名玩家腳下落電，造成範圍傷害
  2. 第二段：落地後擴散傷害到周圍
  3. 第三段：場上留下一個持續性電圈

應對方法

  • 被點名後立刻持續跑動拉開黃圈位置
  • 把電圈拉到場地邊緣，避免擋住其他機制動線
  • 未被點名玩家也要保持距離，避免被擴散傷害波及
重要提醒
不要用三段跳規避！跳起來反而會被空中拉扯抓住。跑動才是正解。
機制循環
二階段三大機制（無常索命 → 飛羽追魂 → 哭喪電網）循環之間，會穿插出現索魂追命圈。出現時機沒有固定規律，要隨時做好應變準備。

被點名後跑動把電圈拉到場邊，避開機制動線
